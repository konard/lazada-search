# Whey manufacturer source expansion

This source-only checkpoint maps all **26** strict chocolate/plain whey manufacturer gaps from the frozen input snapshot. It contains **32** unchanged original source bodies: **15** reused cached sources and **17** new manufacturer responses, including one retained HTTP 404. Every source has a URL, original observation time, body SHA-256, storage digest, and artifact path in [review.json](review.json). The scripts make no shared-store changes.

The manufacturer facts below are exact factory candidates. They do not prove that a seller's selected package contains the same revision. No new manufacturer reviews were applied. Existing matched IT'S JUST and MusaKing reviews remain reusable without redownloading their sources. Prices, availability and delivery belong to the separate live capture workflow.

The structured facts also include sugar, fat, saturated fat, calories, ingredients and allergens where explicitly published. Rule1's plain panel declares zero sugar and fat, with whey isolate, hydrolyzed whey isolate, soy lecithin and sunflower lecithin. Clean Simple Eats declares sugar **less than 1 g**, which is retained as a bound; its omitted saturated fat is absent rather than zero. Plain whey and chocolate variants remain separate.

The remaining gap records preserve concrete blocking evidence: old Critical and Mutant formula revisions, a Warrior seller panel showing Strawberry Creme, ProSupps package revision, Optimum seller repacks without parent factory identity, an unidentified VBest manufacturer, and the unresolved Muscle Nation 300 g product family. The [official Muscle Nation introduction](https://musclenation.org/blogs/blog/we-are-releasing-15-new-products-in-coles) identifies Milk Chocolate Daily Shake as a whey and milk protein blend; its linked product returns 404, retained here without retrying. Similar brand names or generic marketing never substitute for exact labels.

All original HTML is stored compressed without alteration. Reused public page HTML is explicitly identified as a prior capture, not a fresh HTTP response. Newly fetched image bytes are retained in their original formats. SHA-256 always refers to the decompressed original HTML or unchanged image body; `storageSha256` additionally checks the stored artifact.

New source requests use a persistent per-host interval of at least 61 seconds and existing cache hits. The initial local Python certificate configuration error produced no HTTP response; it was corrected using the verified system CA bundle. No private page, account data, Lazada request, browser action or density conversion is part of this checkpoint.

Rebuild only this directory with `python3 docs/acceptance/whey-source-expansion/build-review.py`. [input-snapshot.json](input-snapshot.json) keeps the original public worklist and catalog digests stable. [validation.json](validation.json) records digest checks and mapping counts. A later integration must independently match each selected seller SKU's original front/back, flavour, formula revision, grams and food pack count before applying a manufacturer review.

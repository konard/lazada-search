## Reproduce without source requests

```sh
node scripts/replay-package-volume-reviews.mjs
node scripts/archive-case.mjs --offline --no-ocr --data-dir .lazada-search/offline-volume-reviews --archive-dir data/cases/vietnam-nha-trang
node bin/lazada-search.js archive-verify --offline --no-ocr --archive-dir data/cases/vietnam-nha-trang
```

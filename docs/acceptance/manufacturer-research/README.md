# Preserved manufacturer research

This checkpoint imports seventeen preserved manufacturer source artifacts into the shared associative store and replays them offline. Fifteen original bodies, JSON responses and label images retain their hashes and actual observation dates. Two HTML bodies are redacted derivatives: unrelated Mapbox access tokens are removed and both original and derivative digests are recorded. Unknown historical capture dates remain explicit. Twelve originals were already committed; three new factory pages establish the Cremo brand domain with reciprocal corporate links. The new pass made four direct source attempts, including one TLS failure, and approved no exact package facts. Two further SFD sources retain corporate ownership proof and the exact shop HTTP403 challenge; that failure is cached without retry. The offline replay itself makes zero downloads. The registry identifies the publisher; it does not establish an exact selected SKU.

Reproduce the public source replay:

```sh
node scripts/archive-manufacturer-research.mjs
node scripts/archive-case.mjs --offline --no-ocr
node bin/lazada-search.js archive-verify --offline --no-ocr
```

- Happy's 2021 laboratory sample cannot establish current retail nutrition. Both 125 ml and 475 ml require current exact labels.

- Merino's multi-option retailer barcode 8936011774024 identifies the vanilla option. The chocolate brown-rice candidate 8936011774031 requires original wrapper confirmation.
- Häagen-Dazs full-label OCR changes `4.0 g` to `40 g` and `4.5 g` to `45 g`. The [image-backed crop replay](../decimal-ocr/README.md) recovers both decimals and preserves derived-image/TSV hashes. These review-only results do not establish the exact Lazada package identity.

`ManufacturerResearch` collects only registered public HTTPS sources, paces requests, caches failures, and stops downloads when the persistent CAPTCHA checkpoint is active. Label assets must appear in a preserved official parent page. Reviews require exact brand, product, flavour, market, package, current formula, and GTIN or manufacturer variant code for every claimed source. Each numeric value and its nutrition basis must appear in source-bound excerpts. Mass and volume are independent fields.

The library, CLI, local HTTP and Telegram operations expose research and resumable translation. These workflows preserve partial evidence; successful fixture tests do not prove complete live manufacturer coverage, correct whole-catalog English, or frozen delivery to Nha Trang. See [all requirements](../../REQUIREMENTS.md), [collection operations](../../COLLECTION.md), and [translation operations](../../translation.md).
